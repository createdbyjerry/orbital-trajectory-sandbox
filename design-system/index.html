Orbital Trajectory Sandbox — Design System

Reference documentation for the theme, color palette, typography, and UI components used to build the Orbital Trajectory Learning Sandbox prototype. High-contrast, monochrome, glass-panel aesthetic inspired by mission-control / orbital-schematic instrumentation. Every value below is a named token. The same names and values are shared with the prototype's CSS through assets/css/tokens.css, which is generated from tokens/tokens.json (W3C design-tokens format, importable into Figma via Tokens Studio).

v1.2 · mobile layout · values read live from tokens.css

Theme

The visual language treats the interface as instrument overlays floating above a live 3D scene: near-black backgrounds, thin hairline borders, frosted-glass panels, and sparing use of color so data — not chrome — draws the eye.

Monochrome, high contrast

Nearly everything is white, grey, or black. Line weight, opacity, and stroke style (solid / dashed / dotted) carry meaning instead of hue.

One accent color

Red (--color-accent · #ff4d4d) is reserved exclusively for critical or live-dynamic data — impact/crash states, the velocity vector, and ground-track markers.

Glassmorphism panels

Controls float in translucent, blurred cards (backdrop-filter: blur()) rather than opaque sidebars, keeping the 3D scene visible underneath at all times.

Progressive disclosure

Every panel section is a native <details>/<summary> so users can collapse what they don't need — no custom JS accordion required.

Two views on small screens

At or below 768px the Orbit Overview pane is dropped. The Ground Track (kept at 2:1) sits above the 3D View, which fills the rest of the screen.

Everything collapsed by default on mobile

On mobile all controls start hidden behind an icon dock. Each icon opens one sheet (Presets, Elements, Simulation, Telemetry, How it works), so only one container is ever on screen.

Responsive & Mobile

One breakpoint switches the app from three floating panels to a two-view layout with an icon dock. CSS media queries can't read custom properties, so main.css repeats the breakpoint values; main.js reads them from the tokens so the JavaScript and CSS always agree.

Icon dock — five icon buttons, one per container. Monochrome 1.5px stroke icons at --size-icon; the open sheet's button gets the glass-hover fill and a hairline border. In landscape it becomes a vertical rail with labels hidden.

Bottom sheet — the mobile form of a floating panel. Denser glass (--color-glass-solid), --radius-24 top corners, upward --shadow-sheet, a grab handle, and a sticky header whose × collapses it. Slides in over --duration-sheet with --easing-standard; motion is removed for reduced-motion users.
